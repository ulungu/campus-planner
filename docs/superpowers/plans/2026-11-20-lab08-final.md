## Что уже выполнено (ЛР 1–7)
Авторизация и выход, список с загрузкой/пустым состоянием/ошибкой, CRUD через API, фильтр + поиск,

обработка 404 / ошибок API / 401.

## Этапы
1. **Ревизия и исправления**
   - Тексты ошибок: `getErrorMessage` больше не показывает сообщения сервера — текст выбирается по HTTP-статусу
     (требование «пользовательские тексты не содержат технических сообщений сервера»). Для входа — отдельный текст при 401.
   - Обновление данных при возврате приложения из фона: `focusManager` + `AppState`.
   - Повторяющаяся разметка → компоненты `LoadingState`, `ErrorState`, `TaskNotFound`
     (экраны деталей, редактирования, списка, создания).
2. **Собственная функция — сортировка по дедлайну**
   - `TaskSort = 'created' | 'dueDate' | 'priority'` в UI-контексте; чистая `sortTasks(tasks, sort)` в `utils/task.ts`:
     по сроку — ближайшие сверху, без срока — в конце, при равенстве — по приоритету.
   - Переключатель `SortSelector` под фильтром статуса.
   - Подпись срока на карточке: «Сегодня», «Завтра», «Через N дн.», «Просрочено на N дн.» (`describeDueDate`).
   - Пустое состояние — общее со списком.
3. **Документация**: README (все пункты ЛР8, без учётных данных), `docs/screenshots/` под 3–5 скриншотов,
   `docs/demo-script.md`, `eas.json` с профилем `preview` (APK) и пошаговый план сборки.
4. **Проверка**: `npx tsc --noEmit`, grep на `console.log`, `any`, вызовы API в JSX; коммиты по этапам.
