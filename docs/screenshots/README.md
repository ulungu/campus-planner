# Скриншоты для README

Положите сюда PNG-файлы с этими именами (их подхватывает корневой README):

| Файл | Что снять |
| --- | --- |
| `login.png` | экран входа |
| `list.png` | список задач с прогрессом, фильтром и сортировкой |
| `details.png` | экран задачи |
| `sort-due-date.png` | список с сортировкой «По сроку» и подсказками «Сегодня», «Просрочено на N дн.» |
| `dark.png` | любой экран в тёмной теме |
| `emulator.png` | (если нет EAS) успешный запуск в Android Emulator |
