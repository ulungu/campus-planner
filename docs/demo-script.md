# Сценарий демонстрации (до 3 минут)

Перед показом: в аккаунте 4–6 задач, у двух есть срок (один — сегодня или вчера), одна выполнена.

| Время | Что показать | Что сказать |
| --- | --- | --- |
| 0:00–0:15 | Экран входа | Campus Planner — планировщик учебных задач; данные на сервере, у каждого студента свои |
| 0:15–0:35 | Вход своей учётной записью | Токен хранится в SecureStore, при перезапуске сессия восстанавливается |
| 0:35–1:15 | Список → создать задачу со сроком → открыть → отредактировать | Данные через REST API и TanStack Query; после изменений кэш обновляется сам |
| 1:15–1:45 | Свайп вправо (статус), свайп влево (удаление → «Отменить») | Жесты Gesture Handler, анимации Reanimated: статус, прогресс-бар, плашка отмены |
| 1:45–2:15 | Фильтр «Активные», поиск, обновление жестом вниз | Фильтр выполняет сервер, поиск — по загруженному списку |
| 2:15–2:40 | Сортировка «По сроку», подсказки «Сегодня» / «Просрочено» | Собственная функция: ближайшие дедлайны сверху |
| 2:40–2:50 | Настройки → тёмная тема | Тема сохраняется между запусками |
| 2:50–3:00 | Выход | Токен удаляется, кэш задач очищается |

Запасной сценарий ошибок (если спросят): включить авиарежим и потянуть список — ошибка и «Повторить»,
выхода из аккаунта нет.
