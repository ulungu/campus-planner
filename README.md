# Campus Planner

Мобильный планировщик учебных задач студента: задачи по предметам с приоритетом и сроком,
отметка выполнения свайпом, фильтр, поиск и сортировка по дедлайну. Данные каждого пользователя
хранятся на учебном сервере и доступны после входа.

**Предметная ветка:** Campus Planner.

## Возможности

- Вход учебной учётной записью и выход; сессия сохраняется между запусками (токен в SecureStore).
- Список своих задач с сервера: загрузка, пустое состояние, ошибка с кнопкой «Повторить», обновление жестом вниз.
- Создание, просмотр, редактирование и удаление задачи через API; отмена удаления.
- Фильтр по статусу (выполняется на сервере) и поиск по названию и предмету.
- **Сортировка по дедлайну** — собственная функция (см. ниже).
- Свайп карточки: вправо — сменить статус, влево — удалить с подтверждением.
- Анимации Reanimated: смена статуса карточки, раскрытие подробностей, подсветка новой задачи,
  прогресс выполнения, появление и исчезновение карточек, плашка «Отменить».
- Светлая и тёмная тема (переключается в настройках, выбор сохраняется).
- Черновик новой задачи сохраняется и предлагается к восстановлению.
- Обработка ошибок: нет сети, ошибка сервера, отсутствующая задача (404), истёкшая сессия (401 — выход на экран входа).

## Собственная функция: сортировка по дедлайну

Под фильтром статуса — переключатель **«Сортировка: Новые / По сроку / По приоритету»**.

- **Новые** — порядок сервера, от новых задач к старым.
- **По сроку** — сверху активные задачи с ближайшим или уже прошедшим сроком; при одинаковом сроке выше приоритет;
  задачи без срока — после них; выполненные — в конце.
- **По приоритету** — высокий, средний, низкий.

На карточке активной задачи со сроком показывается подсказка: «Сегодня», «Завтра», «Через N дн.»
(оранжевым, если осталось 3 дня или меньше) или «Просрочено на N дн.» (красным).

Сортировка применяется поверх серверного фильтра и поиска, поэтому работает с любым из них.
Если задач нет, показывается общее пустое состояние списка («Список пока пуст», «Нет активных задач» и т. п.).

Код: `sortTasks`, `sortByDueDate`, `describeDueDate` в `src/utils/task.ts`, `SortSelector` в `src/components/task/`.

## Стек технологий

| Область | Технологии |
| --- | --- |
| Платформа | Expo SDK 58, React Native 0.88, React 19, TypeScript (strict) |
| Навигация | Expo Router, защищённые маршруты `Stack.Protected` |
| Серверные данные | REST API (`fetch`), TanStack Query 5 (`useQuery`, `useMutation`, инвалидация кэша) |
| Авторизация | Bearer-токен, `expo-secure-store`, восстановление сессии через `/auth/me` |
| Анимации и жесты | Reanimated 4, react-native-gesture-handler |
| Локальное хранение | AsyncStorage (тема, черновик) |

## Запуск

Требуется Node.js 20+ и приложение Expo Go на телефоне (или Android Emulator).

```bash
git clone <адрес репозитория>
cd campus-planner
npm ci
cp .env.example .env        # затем впишите адрес учебного API
npx expo start
```

Откройте QR-код в Expo Go (Android) или камерой (iOS). Для эмулятора нажмите `a` в терминале Expo.

### Адрес учебного API

Адрес задаётся переменной окружения в файле `.env` в корне проекта:

```
EXPO_PUBLIC_API_URL=https://<адрес-учебного-api>
```

Адрес выдаёт преподаватель. Без завершающего `/` и без `/api`. После изменения `.env` перезапустите `npx expo start`.
Файл `.env` не попадает в git; паролей и токенов в нём хранить нельзя.

### Учётные данные

Логин и пароль выдаются преподавателем каждому студенту. В репозиторий они не включаются.

## Структура проекта

```
app/                  экраны (Expo Router)
  (auth)/login.tsx    вход
  (app)/              защищённый раздел: список, задача, создание, редактирование, настройки
src/
  api/                fetch-клиент, функции API задач и авторизации, QueryClient
  auth/               AuthContext, хранение токена
  features/tasks/     хуки TanStack Query: ключи, запросы, мутации
  components/         UI-компоненты и компоненты задач
  context/            тема, UI-состояние списка (фильтр, сортировка)
  utils/              чистые функции: фильтрация, сортировка, сроки, валидация
```

## Сборка для Android (EAS Build)

В `eas.json` есть профиль `preview`: устанавливаемый APK для внутреннего распространения.
Профиль сборки согласуется с преподавателем.

1. Установить EAS CLI и войти: `npm install -g eas-cli`, `eas login`.
2. Привязать проект: `eas init` (запишет `projectId` в `app.json`).
3. Передать адрес API в сборку — `.env` в EAS не загружается:
   `eas env:create --name EXPO_PUBLIC_API_URL --value https://<адрес-учебного-api> --environment preview --visibility plaintext`.
4. Собрать: `eas build --platform android --profile preview`.
5. Скачать APK по ссылке из вывода команды или со страницы сборки на expo.dev и установить на устройство.

| Тип сборки | Профиль | Дата создания |
| --- | --- | --- |
| APK (internal) | `preview` | _указать после сборки_ |

Если доступа к EAS нет: запустить приложение в Android Emulator (`npx expo start`, затем `a`) и приложить скриншот
успешного запуска в `docs/screenshots/emulator.png`.
